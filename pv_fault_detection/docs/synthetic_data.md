# Synthetic Data

## Overview

Two independent generators, one QC gate, one mixing module (spec Section 11).

## Electrical Generator (primary data source)

- `src/synthetic/electrical_sim.py` — pvlib single/two-diode model
- Fault injection parameters: `src/synthetic/fault_injection_table.yaml`
- Physical range validation: `src/synthetic/valid_ranges.yaml`
- Storage: `data/synthetic/electrical/<fault_class>/<uuid>.npz`

NEVER hand-roll diode equations — use pvlib (explicit spec decision).

## Image Generator (primary: physics-geometric augmentation, comparison: GAN)

- `src/synthetic/image_diffusion.py` — Physics-motivated geometric augmentation (Gaussian hotspot
  thermal spots, shadow polygon masks, crack lines). **NOT DDPM/Stable Diffusion** — see note below.
- `src/synthetic/image_gan_baseline.py` — DCGAN comparison only
- SSIM filter: reject images below `synthetic.ssim_min_threshold` (default 0.75)
- Storage: `data/synthetic/images/<modality>/<fault_class>/<uuid>.png`
- Sidecar JSON: records `source_real_sample_id` for leakage test

> **Note on diffusion:** Spec Section 11.2 calls for `diffusers`-based DDPM inpainting.
> This requires CUDA + ~4GB model download. In a CPU-only environment, geometric augmentation
> is used instead and documented as a deliberate deviation in `STATUS.md`.
> If CUDA becomes available, replace the body of `generate_synthetic_image()` with the
> actual `diffusers` DDPM pipeline — the function signature and sidecar format stay the same.

## Leakage Prevention (HARD RULE)

Synthetic samples are ONLY generated by conditioning on training-split real samples.
`generate()` functions raise `ValueError` if called with `split != 'train'`.
The leakage test `tests/leakage/test_synthetic_not_from_test_split.py` verifies this.

## Mixing Ratios

| Ratio | Mode |
|---|---|
| 0.0 | Real only |
| 0.1, 0.25, 0.5, 1.0 | Mixed at ratio |
| unlimited | Synthetic only |
| pretrain_finetune | Stage 1: synthetic only, Stage 2: real fine-tune |
| domain_randomized | Synthetic with swept irradiance/temp/camera-noise |

## Extending Fault Injection

Edit `src/synthetic/fault_injection_table.yaml` to add/modify fault parameter ranges.
All changes TO VERIFY against literature. Flag as ASSUMPTION in YAML comments.
